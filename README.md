# GLOBAL MARKET v4

학교 동아리용 모바일 다인 글로벌 시장 시뮬레이션 게임입니다. 모든 주식·가격은 가상 교육용 데이터입니다.

## 포함 기능
- 최대 30명 참가
- 닉네임 2~16자, 중복 방지
- 새로고침/재접속 시 세션 토큰으로 기존 플레이어 복구
- 1회 참가당 시작 현금 1,000만원
- 12턴 / 1턴 5분 / 1~12월
- 대한민국·일본·미국·중국·독일·프랑스·인도·사우디아라비아·UAE·브라질 + BITCOIN
- 매 턴 정확히 14개 뉴스 + 14개 퀴즈를 1:1 연결
- 퀴즈 오답 1회 시 해당 뉴스 퀴즈 영구 실패(재도전 불가)
- 정답 뉴스와 연결된 종목만 거래 가능
- 가상 주가 변동 및 서버 권위 가격 기록
- 종목별 월간 가격 그래프
- 국가별 5종목 비교 그래프(시작=100 정규화)
- 거래 기록: 플레이어/국가/종목/매수·매도/수량/가격/금액/턴/시간
- 플레이어별 월간 총자산 기록
- 사회 선택 이벤트 및 가상 리스크 선택 이벤트(실제 돈과 무관)
- 관리자 페이지: 게임 제어, 뉴스 14개 확인, 참가자별 자산 그래프, 보유종목, 퀴즈 해금/오답 현황, 거래내역 실시간 확인 및 필터

## 실행
```bash
npm install
npm start
```

브라우저: `http://localhost:3000`
관리자: `http://localhost:3000/admin.html`
관리자 코드: `0403`

## Render 배포
- Build Command: `npm install`
- Start Command: `npm start`
- Node: 18 이상

## 주의
현재 저장 방식은 서버 메모리 기반입니다. Render 무료/재시작 등으로 서버 프로세스가 재시작되면 게임 데이터가 초기화됩니다. 학교 행사 당일에는 관리자 페이지에서 참가자 입장 후 게임을 시작하고, 가능하면 행사 중 서버를 재시작하지 않는 것을 권장합니다.
